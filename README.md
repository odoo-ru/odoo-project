Object models for Odoo module and Odoo project

Install
-------
```commandline
uv tool install odoo-project
```

Development
-----------
We need installed `poetry`.
```console
git clone git@github.com:odoo-ru/odoo-project.git

cd odoo-project
```

Run tests:
```console
uv run pytest
```
